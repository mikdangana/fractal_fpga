Fractal FPGA Sort Pipeline - Conversation Summary
====================================================

Project: LSD fractal sort pipeline in VHDL on Xilinx KU3P
Target: 128-bit entries sorted across HBM-backed bins

COMPLETED WORK
--------------

1. Fix Phase 2 read pipelining
   - Root cause: HBM arbiter in fractal.vhd dropped 1-cycle read request pulses when busy with writes
   - Fix: keep hbm_rd_req asserted until response arrives (level signal, not pulse)
   - Result: Phase 2 COMPLETED, 6312 cycles

2. Scale N_BINS properly
   - Changed from hardcoded N_BINS=8 to derived formula:
     n/2^22 <= N_BINS <= min(n/64, 2^26), power-of-2 at upper bound
   - For test (n=40000): N_BINS=512, BIN_ID_BITS=9

3. Fix random number generator
   - UNIFORM_DIST case produced only {-1,0,1} due to rounding
   - Fix: generate full-range 128-bit values using 30-bit chunks via multiple uniform() calls

4. Carry full RAW_PRECISION=128 bits through pipeline
   - Widened sort pipeline from PRECISIONS=49 to RAW_PRECISION=128 bits per entry
   - N_LEVELS=128 (sort all bits), PIPELINE_LATENCY=255
   - BIN_ENTRY_WIDTH = RAW_PRECISION - BIN_ID_BITS = 119 bits per bin entry
   - Phase 2 reconstructs RAW_PRECISION from bin_id + trailing bits

ARCHITECTURE NOTES
------------------
- For datasets small enough for HBM, Phase 1 and 2 are entirely in HBM
- Same pattern applies for DRAM and SSD tiers
- Index-based sort: idx_level carries 3-bit indices, data_delay carries full entries
- reconstruct_final: combinational mux using idx_level permutation + delayed raw data
- HBM arbiter: round-robin between counters, writes prioritized over reads

FUTURE OPTIMIZATIONS (DEFERRED)
-------------------------------
- DRAM/SSD tiered storage: For datasets > HBM capacity. Ports exist but inactive.
- SRAM key storage optimization: Store raw entries in SRAM, route only needed key bit
  per level through pipeline. Reduces data_delay width dramatically.
- Multi-bin flush packing: Group entries from multiple bins into one HBM write during
  Phase 1 flush. Skipped (negligible at scale).
